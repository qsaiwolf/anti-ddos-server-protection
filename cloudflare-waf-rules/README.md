# Cloudflare WAF & Rate Limiting Rules

[العربية](#العربية) | [English](#english)

## English

This folder contains the recommended configurations for **Cloudflare WAF** and **Rate Limiting**. 
These rules protect your web application against malicious bots, automated scripts, and layer 7 DDoS (HTTP Flood) attacks.

Please refer to [CLOUDFLARE_RULES.md](CLOUDFLARE_RULES.md) for the exact rules and instructions on how to set them up in your Cloudflare dashboard.

---

## العربية

هذا المجلد يحتوي على الإعدادات الموصى بها لقواعد الجدار الناري **Cloudflare WAF** وتقييد الطلبات **Rate Limiting**.
هذه القواعد تحمي تطبيقك من البوتات الخبيثة، والسكربتات المبرمجة، وهجمات إغراق السيرفر (DDoS Layer 7).

يرجى مراجعة ملف [CLOUDFLARE_RULES.md](CLOUDFLARE_RULES.md) للحصول على القواعد بالتفصيل وطريقة إضافتها في لوحة تحكم Cloudflare الخاصة بك.
